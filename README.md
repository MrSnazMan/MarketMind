# MarketMind

AI-powered stock research assistant. Search a ticker to view key financial metrics and ask an AI chat assistant questions about the company, grounded in real financial data.

## Status
🚧 In development

## Tech stack
- Backend: FastAPI (Python)
- Frontend: React + TypeScript (Vite)
- Data: yfinance
- AI: Gemini API
